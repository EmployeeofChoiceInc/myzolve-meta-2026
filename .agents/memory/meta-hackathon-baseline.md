name: MyZolve LIFE hackathon baseline
description: Scope and attribution rules for the Meta Global AI Developer Hackathon work.
---

For MyZolve LIFE hackathon work, document pre-existing MyZolve Connect capabilities separately from all work completed during the hackathon. Do not describe existing Connect functionality as a hackathon creation. Keep the production Connect application unchanged until the baseline and isolated implementation approach are established.

**Why:** The competition requires a defensible before-and-after account, and production functionality must be preserved.

**How to apply:** Before implementing hackathon features, record the starting state and create a separate branch or project. Track all subsequent changes in the hackathon changelog.
